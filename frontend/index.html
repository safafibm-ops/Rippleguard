      The question this tool answers

      A vulnerability score tells you how bad a flaw is.
      It does not tell you how a compromise would travel.

      RippleGuard scores every dependency twice. The exploit channel asks whether a known vulnerability is reachable from your code — what every scanner already does. The trust channel asks something else: if a malicious version of this package were published in the next hour, would your build inherit it automatically? Install hooks run during npm install whether or not your code ever imports the package, so reachability cannot see that path at all.

      Then it simulates a compromise, measures the blast radius, and re-scores the whole tree under five different fixes so you can see which action actually buys you something.
